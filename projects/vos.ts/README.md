# vos (TypeScript)

TypeScript workspace for **VOS — Virtual Object Schema**.

## Packages

| Path        | Package                  | Role                                       |
|-------------|--------------------------|--------------------------------------------|
| `vos/`      | `@game-gpt/vos`          | Schema toolkit (minimal check API for now) |
| `homepage/` | `@game-gpt/vos-homepage` | Language site + playground                 |

## Develop

```bash
pnpm install
pnpm dev
```

Homepage:

- `/` language home
- `/playground` schema playground

See the repository root [`README.md`](../../README.md).
